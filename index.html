rclone-gdrive-kamet-series

rclone-gdrive-kamet-series is a personal tool that lets one person, its developer, access their own Google Drive from their own Linux computer using the open-source program rclone. It is used to browse, copy and back up the developer's own files between Google Drive and their own machines.

The app is not offered to the public and has no other users. It has no website features, accounts or servers; this page exists only to describe the app.

Google user data

The app asks for access to Google Drive so rclone can read and write the signed-in person's own files. It does not collect, sell or share that data with anyone. See the Privacy Policy for details and the Terms of Service.
