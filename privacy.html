Privacy Policy

← rclone-gdrive-kamet-series

Last updated: 13 October 2026

rclone-gdrive-kamet-series is a personal tool used only by its developer to access the developer's own Google Drive from their own computer with the open-source program rclone. It is not offered to anyone else.

What the app accesses

When the developer signs in, the app is granted access to the developer's own Google Drive. It reads and writes the developer's own files only so that rclone can list, copy and synchronise them with the developer's own computers.

How the data is used and stored

  • Files and file information are transferred directly between Google Drive and the developer's own computer. They do not pass through any server operated by the developer.
  • The sign-in token and the app's credentials are stored only in a private configuration file on the developer's own computer.
  • The app has no servers, no database, no analytics and no advertising.

Sharing

Google user data is not sold, shared, transferred or disclosed to anyone, and is not used for advertising or for training any machine-learning model.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be removed at any time at myaccount.google.com/permissions. Deleting the private configuration file on the developer's computer removes the stored token.

Contact

Questions: open an issue or contact pandeytapan on GitHub.
